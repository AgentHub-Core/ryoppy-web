# Web Alpha v0.3 仕様差分

## 目的

GitHub Pages上で、位置情報連動型の歴史図鑑ゲームの中核となる「探索、遭遇、会話、図鑑登録」を短時間で検証する。

## v0.3の対象

- 地域: Cincinnati Streetcar沿線
- 探索範囲: Streetcar沿線の6スポット
- 人物: Christian Moerlein
- 状態: 探索地図、距離判定、信号検出、全画面遭遇、三段階の物語、選択式質問、図鑑登録
- キャラ差分: 通常、会話、獲得
- 保存: localStorage
- 位置確認: ブラウザ現在地と位置デモ
- 音声: ブラウザ読み上げ
- 配信: PWAマニフェスト、Service Worker、GitHub Pages

## 画面原則

- 地図は観光案内一覧にせず、人物と遭遇するための探索画面にする
- 未発見地点は脈打つ信号だけを見せ、発見後に人物の顔と名前へ変える
- 現在地、信号までの距離、遭遇可能範囲をひとつの画面で理解できるようにする
- 人物を画面の主役にする
- 遭遇中はサイト型のナビゲーションを表示しない
- 本文は18px以上を基本とする
- キャラは不規則な小さな移動と呼吸表現で常に動かす
- 台詞と操作ボタンは固定し、動きの影響を受けない

人物一覧、資産グラフ、写真、購入導線は、この遭遇体験の検証後に再評価する。
