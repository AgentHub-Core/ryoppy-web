# りょっぴー Web Alpha 仕様差分

## 目的
GitHub Pagesで公開できる静的Webアプリとして、iOS Alphaの中核体験をブラウザで試せる状態にする。

## 実装済み
- 1950年代アメリカン・ポップのレスポンシブUI
- 3人物、6スポット、18関係ノード
- ブラウザ位置情報と位置デモ
- 人物との遭遇、導入、図鑑登録
- 人物の台詞直下に選択式質問を表示
- ブラウザ読み上げ
- 現代ドル換算の推定資産、戦闘力、ランク
- 富の内訳ドーナツグラフ、資産推移グラフ
- 写真撮影、写真選択、ブラウザ内保存
- モック購入
- Service Workerによる主要アセットのキャッシュ
- GitHub ActionsによるPages公開

## 保存方式
- 人物進捗、関係ノード、設定: localStorage
- 写真: IndexedDB
- 保存単位: ブラウザと端末

## Web固有の条件
- 位置情報はHTTPS公開後に利用可能
- 読み上げ声質はブラウザとOSで変化
- 購入はモック
- 簡易マップは6スポットを示すレトロな独自図
